Nav bar / language flash / speed fixes — 2026-10-11

PROBLEMS FOUND
1. English text showed first, then switched to Telugu. Page text is written
   in English in the HTML and only translated after ~14 JavaScript files load,
   and the browser painted the English version in between.
2. Nav bar blinked on every page change. Only home.html had the header in its
   HTML; every other page started with an empty header that JavaScript filled
   in later. The language pill also showed "Eng" before switching, and the
   Google Fonts file loaded after first paint, so nav text re-flowed.
3. Extra loading cost: Google Fonts (2 extra connections), a 1024px logo shown
   at 220px, a 760px footer logo shown at 75px, a JPG background where a smaller
   WebP existed, a hidden splash image still downloading, and CMS text fetched
   from Supabase on every new tab (5-minute session-only cache).
4. Already-visible sections were hidden and faded back in on load ("blank first").
5. about/privacy/terms/refund threw "pujas is not defined" (main.js).

WHAT CHANGED
- scripts/prerender-header.js (NEW) — bakes the nav bar from navbar.js into every
  public page and adds a shared <head> block. RE-RUN IT after editing the header
  template in frontend/assets/js/navbar.js:   node scripts/prerender-header.js
  The <head> block: hides translatable text until translated (released by
  language.js, with a 2.5 s safety fallback), self-hosted fonts, smooth page
  transitions that keep the nav bar fixed (Chrome/Edge/Safari), and
  prefetching of pages on hover.
- assets/js/navbar.js — header markup in headerHTML(); pre-rendered header is
  only wired up, never rebuilt. New small logos.
- assets/js/language.js — reveals text after translation (waits max 400 ms for
  first-ever CMS load).
- assets/js/cms-renderer.js — CMS text cached in localStorage, applied instantly,
  refreshed in the background only when older than 5 minutes.
- assets/js/animations.js — on-screen sections are no longer hidden/faded in.
- assets/js/main.js — no crash on pages without the puja list.
- assets/css/fonts.css + assets/fonts/ (NEW) — Poppins + Anek Telugu self-hosted.
  Note: Hindi text now uses the device's Devanagari font (Poppins Devanagari is
  not available for self-hosting in this package).
- images: logo-header.webp (20 KB, same visible crop), s_logo-footer.webp (10 KB),
  CSS background now bg-pattern.webp.
- backend/controllers/websiteContentController.js — serves last good CMS content
  instantly and refreshes from Supabase in the background (admin saves still
  clear it immediately).
- backend/utils/http.js — font MIME types.
- tests/menu-language.test.js — updated for the new release logic. 26/26 pass.

ROUND 3 — PageSpeed items
----------------------------------------------------------------
- Images: puja/temple cards and hero now request Supabase resized versions
  (/render/image/...?width=N), with automatic fallback to the original file if the
  resize endpoint is unavailable; width/height set to stop layout shift.
- Home hero image + preloads baked at build time (desktop / tablet / phone).
- scripts/build-static.js minifies the per-page CSS bundles (comments/whitespace
  only). Set SS_NO_MINIFY=1 to get readable bundles. Checked: computed styles of
  6,152 elements on 10 pages x 2 screen sizes match the unminified build (one
  auto-margin value on booking.html varies run to run even without minifying).
- fonts.css is now inlined in the shared <head> block (prerender-header.js), so
  fonts no longer wait for an extra render-blocking CSS request.
- navbar.js: header height measured in requestAnimationFrame (removes a forced reflow).
- vercel.json: cache rules for fonts/bundles/images are explicit and cannot be
  overridden by the generic /assets rule.
- Merged from your live zip: backend/utils/http.js and the "npm test" script.
